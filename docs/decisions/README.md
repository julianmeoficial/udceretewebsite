# Architecture Decision Records (ADR)

Registro breve de decisiones técnicas con impacto duradero.

## Formato

Cada ADR vive en `docs/decisions/NNNN-titulo-corto.md` y contiene:

1. **Estado** — propuesta · aceptada · diferida · sustituida
2. **Contexto**
3. **Decisión**
4. **Consecuencias**
5. **Alternativas consideradas**
